# 献血できる？（kenketsu-dekiru）

献血の基準（年齢・体重・前の献血からの間・1年の量）を当てる1日5問の学習ゲーム。架空の人の性別・年齢・体重・前の献血を見て、したい献血（200mL・400mL・血漿成分・血小板成分）が「今日できる・日をあければできる・いまの年齢・体重ではできない」のどれかを選び、できないときは正解したらどの基準で決まったかも選ぶ。1年の数え方・65歳からの献血など、しくみの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/kenketsu-dekiru/>

- 中身は国の省令「安全な血液製剤の安定供給の確保等に関する法律施行規則」別表第二（採血の基準）<https://laws.e-gov.go.jp/law/331M50000100022> に書いてあることだけです。日本赤十字社の献血基準 <https://www.jrc.or.jp/donation/about/terms/> も見てください。
- 出てくる人はすべて架空で、問題の場面は練習のための例です。
- このゲームは医療の助言ではありません。献血できるかは、当日の血圧・血液の検査と問診で決まります。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
